# Prueba y Verás

Aplicación móvil educativa para niños de 8 a 12 años. El niño ayuda a
Chirimbolo, un invento a medio armar, y a los isleños del archipiélago,
diseñando pruebas justas: dos montajes que solo pueden diferir en una
variable, para descubrir de verdad qué causa cada resultado.

## Compilar

```bash
./gradlew assembleDebug
```

## Pruebas

```bash
./gradlew testDebugUnitTest
```
